# BehaviorLab 0.1.1 · Windows x64 免安装版

将原项目的飞蝗检测、ByteTrack 追踪和产卵时序分析封装为桌面软件，支持批量录像分析、视频预览、时段复核、保存项目和导出 CSV。
默认每段录像选出一个最佳产卵候选时段，结果需要人工复核。

## 开始使用

1. 完整解压完整版 ZIP，到可写文件夹中打开 `BehaviorLab.exe`。保留同级 `_internal` 和 `models`。
2. 点击“添加视频”，然后点击窗口顶部蓝色“开始批量分析”，或按 F5。
3. 分析完成后复核时段，使用“修正”“确认”“排除”或“添加时段”。
4. “保存项目”便于继续复核，“导出 CSV”用于结果统计。

更新 0.1.0 前请先保存项目并关闭软件，再将更新包解压到旧版目录，覆盖同名文件。
更新包不含模型、`data/` 或原视频。

## 本版内容与验证

- 程序与模型分开管理，支持导入 `.behavior.zip` 模型包。
- 开始/停止按钮固定在顶部，左侧设置可滚动；改善小屏幕和显示缩放下的操作。
- CPU ONNX 推理，无需另装 Python、PyTorch 或 CUDA。在 Windows 11 x64 上测试，其他系统未单独验证。
- 13 项自动测试、9 组窗口/缩放布局检查，以及桌面操作和独立 EXE 流程检查通过，详见仓库 `docs/VALIDATION.md`。
- 默认模型由原项目 **v1.0** 附件 `best.pt` 转换；模型包内提供来源、权重校验值及许可证文件。本次桌面版本标签为 **desktop-v0.1.1**，与原模型版本独立。

## 使用边界

**本次没有在带人工标注的真实实验录像上重测识别准确率。原项目历史精度不等于桌面软件的实测精度。**
兼容模型接口包括 YOLO8/11 检测和 RGB 单帧互斥分类；更换检测器仍需匹配的行为规则。姿态、分割或视频片段网络需要新增适配器。
视频按帧读取，不批量导出图片；开启缓存会产生 JSON 轨迹文件，缓存当前没有自动容量上限。可在停止分析或关闭软件后清理 `data/cache/`。
软件未做代码签名。

操作和模型接口见仓库 `docs/DESKTOP.md`、`docs/MODEL_PACK.md`；第三方信息见 `THIRD_PARTY.md`。
